# BTK Akademi - Sıfırdan İleri Seviye Python Programlama

Bu depo, [BTK Akademi](https://www.btkakademi.gov.tr/) üzerinden tamamladığım **[Sıfırdan İleri Seviye Python Programlama](https://www.btkakademi.gov.tr/portal/course/sifirdan-ileri-seviye-python-programlama-5877)** kursu süresince yaptığım tüm çalışmaları, örnek kodları, veri analizi pratiklerini ve projeleri içermektedir.

---

## 🚀 Kurs Hakkında

Kurs, temel seviyeden başlayarak Python programlama dilini tüm detaylarıyla öğretmeyi ve katılımcıları ileri seviye konulara (Nesne Yönelimli Programlama, Veri Analizi, Veritabanı Yönetimi, Web Scraping, GUI ve Web Geliştirme) taşımayı amaçlamaktadır.

---

## 📂 Depo İçeriği

Kurstaki ilerleyişe paralel olarak oluşturulan klasör yapısı ve işlenen konular:

*   **Temel Python Kavramları & Veri Yapıları:** Değişkenler, veri tipleri, koşullu durumlar (`if/elif/else`), döngüler (`for/while`), listeler, demetler (tuples), sözlükler (dictionaries), kümeler (sets).
*   **Fonksiyonlar & İleri Seviye Özellikler:** Parametreler, kapsam (scope), lambda, decorators, iterators ve generators.
*   **Nesne Yönelimli Programlama (OOP):** Sınıflar (Classes), nesneler, kalıtım (inheritance), kapsülleme ve dunder metotlar.
*   **Hata Yönetimi & Dosya İşlemleri:** `try/except/finally` blokları, dosya okuma/yazma (`open`, `read`, `write`).
*   **Web Scraping & Otomasyon Botları:** `requests`, `BeautifulSoup` ve `Selenium` ile bot uygulamaları.
*   **Veri Analizi & Görselleştirme:** `NumPy`, `Pandas` ve `Matplotlib` ile veri işleme ve grafik oluşturma.
*   **Veritabanı Yönetimi:** İlişkisel (`SQLite`, `MySQL`) ve NoSQL (`MongoDB` / `PyMongo`) veritabanı entegrasyonları.
*   **Masaüstü Uygulamaları:** `PySide6` ile Grafiksel Kullanıcı Arayüzü (GUI) geliştirme.
*   **Web Geliştirme:** `Bootstrap 5` frontend temelleri ve `Django` web framework kullanımı.

---

## 🛠️ Kullanılan Teknolojiler

*   **Dil:** Python 3.12+
*   **Kütüphaneler & Frameworkler:** Pandas, NumPy, Matplotlib, PySide6, Django, Selenium, BeautifulSoup4, PyMongo
*   **Geliştirme Ortamı:** VS Code

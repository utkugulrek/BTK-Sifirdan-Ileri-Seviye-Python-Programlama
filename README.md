# BTK Akademi - Sıfırdan İleri Seviye Python Programlama

Bu depo, [BTK Akademi](https://www.btkakademi.gov.tr/) üzerinden aldığım **[Sıfırdan İleri Seviye Python Programlama](https://www.btkakademi.gov.tr/portal/course/sifirdan-ileri-seviye-python-programlama-5877)** kursu süresince yaptığım çalışmaları, örnek kodları ve pratikleri içermektedir.

---

## 🚀 Kurs Hakkında

Kurs, temel seviyeden başlayarak Python programlama dilini tüm detaylarıyla öğretmeyi ve katılımcıları ileri seviye konulara (Nesne Yönelimli Programlama, Veritabanı İşlemleri, Web Scraping vb.) taşımayı amaçlamaktadır.

---

## 📂 Depo İçeriği

Kurstaki ilerleyişime paralel olarak klasör yapısı ve işlenen konular zamanla güncellenmektedir:

*   **Temel Python Kavramları:** Değişkenler, veri tipleri, koşullu durumlar (`if/elif/else`), döngüler (`for/while`).
*   **Veri Yapıları:** Listeler, demetler (tuples), sözlükler (dictionaries), kümeler (sets).
*   **Fonksiyonlar:** Parametreler, kapsam (scope), lambda fonksiyonları.
*   **Nesne Yönelimli Programlama (OOP):** Sınıflar (Classes), nesneler, kalıtım (inheritance), kapsülleme (encapsulation), polimorfizm.
*   **Hata Yönetimi:** `try`, `except`, `finally` blokları ve özel hata fırlatma.
*   **Modüller ve Paketler:** Harici modüllerin kullanımı ve kendi modülümüzü yazma.
*   **Dosya İşlemleri:** Dosya okuma ve yazma işlemleri (`open`, `read`, `write`).
*   *(İlerleyen konular eklenecektir.)*
